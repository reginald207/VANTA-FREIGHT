About

A fictional carrier, built for real.

VANTA FREIGHT does not exist. This site is a design and engineering showcase: an interactive film about freight, built with open web technology.

What is real

  • The code, and the real-time 3D it renders
  • The accessibility and performance work
  • The fallbacks for devices without WebGL, or with reduced motion
  • The licences for every library and typeface

What is made up

  • The company, its hubs and its lanes
  • The fleet. Its specifications are measured from the 3D models
  • The services. They are not offers
  • Shipments and tracking, which are simulated in your browser
  • Quotes. The form sends nothing

Design principles

  • Night-shift clarity

    Obsidian surfaces, high-contrast type, and lime only where it means something.

  • Honest data

    No invented statistics, customers or certifications. Simulations are labelled as simulations.

  • Motion with a purpose

    The camera moves to explain something. Every scene also exists as plain, readable HTML.

  • Built to degrade

    No JavaScript, no WebGL or reduced motion: you still get the whole story.

How it is built

Static pages built with Vite, written in plain HTML, CSS and JavaScript modules. The trucks are modelled in code with three.js and lit in real time. The home film is driven by GSAP ScrollTrigger over native scrolling. Playwright tests check every page, every fallback and the bundle budgets.

Accessibility

The site aims for WCAG 2.2 AA: semantic landmarks, visible focus, skip links, sufficient contrast and keyboard access throughout. Use the Reduce motion switch in the header to turn off the film on any page.
